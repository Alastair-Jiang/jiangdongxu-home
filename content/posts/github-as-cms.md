这个网站的项目区没有数据库，没有后台管理，数据直接来自我的 GitHub 仓库。

## 为什么

个人网站最大的敌人是「维护成本」。一旦需要手动同步内容，网站就会慢慢荒废。而我的项目本来就在 GitHub 上——语言、star、更新时间这些信息 GitHub 都已经有了，为什么还要再抄一份？

## 怎么做

- `lib/projects.ts` 维护一个仓库清单（决定哪些仓库进站、怎么分类）
- `lib/github.ts` 在构建时拉取每个仓库的实时元数据
- Next.js 的 ISR 每小时重验证一次，新 push 的仓库会自动出现

## 收益

新增一个仓库 = 改一行配置。网站永远和 GitHub 同步，零手动维护。
